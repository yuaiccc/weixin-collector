# Security and responsible use

This project archives only public WeChat article URLs that a user explicitly supplies.

- It does not ask for, export, or persist browser cookies, passwords, or account credentials.
- It does not automate login, solve CAPTCHA challenges, impersonate a browser, or bypass platform rate limits.
- The desktop app processes links serially. Stop and wait if WeChat shows a verification or access restriction.
- Downloaded material remains subject to the original author's copyright and the platform's rules. Use it for lawful personal reading, research, or authorized archival.

Please report a security issue privately through GitHub's repository security advisory feature. Do not include credentials or personal data in an issue.
